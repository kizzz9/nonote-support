FAQよくある質問

1遊び方がわかりません

マスをタップするか、なぞって塗ります。ダブルタップで×を付けます。行と列の数字は、その列で続けて塗るマスの数です。設定 → 解き方の見本 でいつでも練習できます。

2問題の合間の広告を消したい

設定 → 広告を消す を一度購入すると、次の問題へ進むときの動画広告と画面下のバナーが出なくなり、ヒントも回数を気にせず使えます。同じ Apple ID の別の iPhone でも、購入を復元 で引き継げます。

3購入した内容が反映されません

アプリを開き直してください。それでも反映されないときは 設定 → 購入を復元 を押してください。返金は Apple への申請になり、返金されるとその購入で開いた内容は使えなくなります。

4遊ぶのにお金はかかりますか？

いいえ。最初の猫、すべての曲、遊び方は無料です。ヒントも毎日3回まで無料で、使い切ったら短い動画を見ると追加できます。購入できるのは、猫をもう1匹同時に出す枠や広告を消すなどの追加分だけです。

5機種変更で集めた曲を引き継ぎたい

新しい iPhone で同じ Apple ID の iCloud にサインインすると、集めた曲が自動で戻ります。

6ランキングに参加したい／やめたい

設定 → Game Center のランキング をオンにすると参加します。オフにすると、それ以降は記録を送りません。

7データを消したい

アプリを削除すると、端末内のデータはすべて消えます。iCloud に残った記録は iOS の「設定 → Apple ID → iCloud」から管理できます。詳しくはプライバシーポリシーへ。
